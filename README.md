# Jackaroo Game Engine

A single-player implementation of the classic Middle Eastern board game Jackaroo, built in Java with JavaFX.

## About
This project was written entirely by hand with zero AI assistance. Every line of code — game logic, AI decision-making, state management, and GUI — was implemented manually.

## Features
- Full game engine with all 15 card types and custom rules
- AI decision-making for 3 CPU opponents
- JavaFX graphical interface
- Marble state management (Home Zone, Track, Safe Zone)
- Trap cells, collision logic, and fielding rules

## Tech Stack
- Java
- JavaFX
- OOP design principles
